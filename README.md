# Al-Juman Al-Janabi Laboratory

A local medical laboratory management application for Android and Windows.

## Features

- Patient management
- Patient visits and reports
- Laboratory tests management
- Test results entry
- Automatic reference ranges
- Arabic RTL interface
- English medical test names and units
- PDF and Word report export
- Printing
- User accounts and permissions
- Audit log
- Statistics
- Backup and restore
- Draft and Final reports
- Local database
- Light and Dark themes

## Platforms

- Android
- Windows
